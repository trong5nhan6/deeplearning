# MILK10K_SOLUTION

Pipeline PyTorch để tham gia **ISIC MILK10k Benchmark** — phân loại chẩn đoán tổn thương da đa nhãn.

🔗 Challenge: https://challenge.isic-archive.com/landing/milk10k/
🏆 Metric: **Macro F1** (threshold = 0.5)
📋 Task: 11 lớp chẩn đoán — AKIEC, BCC, BEN_OTH, BKL, DF, INF, MAL_OTH, MEL, NV, SCCKA, VASC

## Cấu trúc dataset thực tế

| File | Mô tả |
|------|-------|
| `MILK10k_Training_Metadata.csv` | **10,480 rows** — 2 rows/lesion (clinical + dermoscopic), chứa `lesion_id`, `image_type`, `isic_id`, `age_approx`, `sex`, `skin_tone_class`, `site`, 7 MONET scores |
| `MILK10k_Training_GroundTruth.csv` | **5,240 rows** — 1 row/lesion, chứa `lesion_id` + 11 label columns |
| `MILK10k_Test_Metadata.csv` | **958 rows** — 2 rows/lesion, không có label |
| `train_combined.csv` *(generated)* | **5,240 rows** — 1 row/lesion, sau khi pivot + merge labels |
| `test_combined.csv` *(generated)* | **479 rows** — 1 row/lesion, không có label |

**Schema của combined CSV:**
```
lesion_id, clinical_path, derm_path,
age_approx, sex, skin_tone_class, site,
clin_MONET_ulceration_crust, ..., clin_MONET_skin_markings_pen_ink_purple_pen,
derm_MONET_ulceration_crust, ..., derm_MONET_skin_markings_pen_ink_purple_pen,
AKIEC, BCC, BEN_OTH, BKL, DF, INF, MAL_OTH, MEL, NV, SCCKA, VASC
```

**Đường dẫn ảnh** được lưu dạng relative path: `IL_0000652/ISIC_8149219.jpg`, resolve theo `image_dir`.

## 2. Chuẩn bị data (chỉ cần chạy 1 lần)

```bash
# Pivot metadata + merge labels → tạo combined CSVs
python src/prepare_data.py --base_dir datasets/MILK10k

# Kết quả:
#   datasets/MILK10k/train/train_combined.csv   (5,240 rows)
#   datasets/MILK10k/test/test_combined.csv     (479 rows)
```

---

## 3. Tạo train/val split

```bash
# StratifiedKFold 5 folds, lấy fold 0
python src/split_data.py \
    --csv     datasets/MILK10k/train/train_combined.csv \
    --out_dir datasets/MILK10k/splits \
    --fold    0 \
    --n_folds 5 \
    --seed    42

# Kết quả: train=4,192 / val=1,048 (stratified theo main class)
```

Để tạo tất cả 5 folds:
```bash
for FOLD in 0 1 2 3 4; do
    python src/split_data.py \
        --csv datasets/MILK10k/train/train_combined.csv \
        --out_dir datasets/MILK10k/splits \
        --fold $FOLD --n_folds 5
done
```

## 4. Training

### Single-image mode (dermoscopy only — mặc định)

```bash
# Swin Transformer Base
python train.py --config configs/swin_base.yaml

# ConvNeXt Base (với Asymmetric Loss)
python train.py --config configs/convnext_base.yaml

# EfficientNet-B3 (với Focal Loss, image_size=300)
python train.py --config configs/efficientnet_b3.yaml

# MaxViT Tiny
python train.py --config configs/maxvit_tiny.yaml

# ViT Base
python train.py --config configs/vit_base.yaml
```

Override config qua CLI:
```bash
python train.py --config configs/swin_base.yaml \
    --epochs 40 --lr 5e-5 --batch_size 16
```

### Dual-image mode (clinical + dermoscopy)

Sửa config hoặc dùng CLI:
```bash
python train.py --config configs/swin_base.yaml --mode dual_image
```

Hoặc trong YAML:
```yaml
mode: dual_image
dual_shared_weights: true   # chia sẻ backbone weights giữa 2 branch
```

### Bật metadata (age / sex / skin_tone / site / MONET)

```yaml
use_metadata: true   # trong file config YAML
```

Model sẽ tự tính `meta_dim=32` và thêm MLP fusion layer.

## 5. Inference & Tạo submission

```bash
# Single-pass inference
python src/infer.py \
    --config     configs/swin_base.yaml \
    --checkpoint outputs/checkpoints/swin_base_patch4_window7_224/best.pth \
    --test_csv   datasets/MILK10k/test/test_combined.csv \
    --out        outputs/submissions/submission_swin.csv

# Với Test-Time Augmentation (TTA, +1-2% F1)
python src/infer.py \
    --config     configs/swin_base.yaml \
    --checkpoint outputs/checkpoints/swin_base_patch4_window7_224/best.pth \
    --test_csv   datasets/MILK10k/test/test_combined.csv \
    --out        outputs/submissions/submission_swin_tta.csv \
    --tta
```

**Format submission:**
```
lesion,AKIEC,BCC,BEN_OTH,BKL,DF,INF,MAL_OTH,MEL,NV,SCCKA,VASC
IL_0006205,0.03,0.71,0.01,...
```

## 7. Loss functions

| `loss_name` | Khi nào dùng |
|-------------|--------------|
| `bce` | Baseline, kết hợp với `use_pos_weight: true` |
| `focal` | Khi class rất hiếm (MAL_OTH 0.2%) |
| `asl` | **Khuyến nghị** cho multi-label imbalance — ConvNeXt config dùng mặc định |

## 9. Recommended strategy để đạt điểm cao

1. **Train 3 model khác nhau** với config mặc định (Swin, ConvNeXt, EfficientNet)
2. **Dùng ASL loss** cho ConvNeXt — hiệu quả nhất với multi-label imbalance nặng
3. **Bật metadata** (`use_metadata: true`) — cộng thêm `meta_dim=32` features
4. **TTA** khi inference — average 4 augmentation variants
5. **5-fold CV + ensemble** — train tất cả 5 folds, average 15 predictions (3 model × 5 fold)
6. **Dual-image mode** — dùng cả clinical lẫn dermoscopy image cùng lúc
